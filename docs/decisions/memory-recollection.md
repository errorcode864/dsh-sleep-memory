# 回忆细节收缩与原文对照

E1 已提供独立的只读回忆视图；自动召回和旧版 `fidelity` 行为保持兼容。
本批按原句抽取，不调用模型、不改写底稿，也不把年龄换算成可信度。

## 使用方式

原文弹窗增加“回忆视图与原文对照”，填写线索后可生成简略回忆、展开细节或显示完整底稿。
对照区标亮已呈现片段，其他文字仍完整保留；省略范围可逐字核对。

工具使用 `memory_manage`：

```json
{
  "action": "recollect",
  "id": "smm_example",
  "projectId": "示例项目",
  "detail": "brief",
  "query": "迁移时的恢复检查"
}
```

继续展开时将 `detail` 改为 `expanded` 或 `original`，并传入前次返回的 `sourceVersion` 作为 `expectedVersion`。
也可先 `get`，使用返回的 `recollectionVersion` 绑定当前底稿。
界面始终传入弹窗底稿版本；发生冲突时清空旧视图并提示刷新。

## 展示规则

| 内容与模式 | 展示规则 |
| --- | --- |
| 事实、显著记忆、明确标注为偏好的记录 | 所有模式保留全文 |
| 普通经历 `brief` | 事件距今不足 30 天为 900 字符；30 至 179 天为 600 字符；180 天起为 300 字符 |
| 普通经历 `expanded` | 原句片段最多 1800 字符 |
| `original` | 当前 ID 的完整底稿 |

年龄从事件结束时间计算，旧记录依次回退到事件开始时间和创建时间，未来事件按 0 天展示。
这些阈值仅是第一版展示策略，不代表经认知科学验证的遗忘规律。

按问题线索给句段排序，再按原文顺序呈现；省略处以省略号标明。
句段以中文句末标点或换行划分，不在句段内部切断；简略最多 24 段，展开最多 48 段。
按固定优先序取能容纳的前缀，较大预算包含简略视图的原文范围。
首段超出预算时返回空片段与完整省略范围，提示进一步展开，避免截断否定条件、日期或数值。
字符限制只计算抽取正文，不是完整 JSON 的 Token 预算；事实和 `original` 可能返回长全文。

## 接口与版本

- `detail` 为 `brief`、`expanded`、`original`，默认 `brief`；`query` 最多 500 字符。
- `expectedVersion` 可选，须为接口返回的 64 位十六进制版本标识；未知参数拒绝。
- `fragments` 提供 `start`、`end`、`text`，`omitted` 提供省略的 `start`、`end`。
- 下标采用 JavaScript UTF-16 的左闭右开区间，所有片段和省略范围恰好覆盖底稿。
- `includedChars`、`omittedChars`、`originalChars` 与上述区间使用同一计数口径。
- `sourceVersion` 绑定正文、范围、类型、层级、事件时间、来源、学习信息、有效状态和来源关系。
- `viewVersion` 额外绑定展示模式、预算、片段与 `formatVersion: 1`；它是派生结果标识，不是持久版本历史。
- `current`、`lifecycle`、`replacedBy` 标明当前有效性；历史 ID 可以显式读取，但不会被标为当前版本。

访问次数、记忆强度和访问时间不改变底稿版本；正文、纠正状态、来源等改变时拒绝过期的对照请求。
版本检查沿用现有串行队列，检查后直接计算视图，不在中间等待模型。
没有 `expectedVersion` 时读取请求当时的快照，调用者若要持续对照应保留版本。

`inferred: false` 只表示本次展示没有新增推断，不证明底稿本身是事实。
深层底稿仍可能是派生概要，原始证据需沿 `traceSources` 或既有 `expandRecall` 读取。
省略的句段仍可能包含约束和反例，不能据片段猜测缺失部分或执行操作。

## 范围与副作用

工具继承会话项目范围，允许读取该范围及全局记忆，不跨项目读取。
原文弹窗显式使用当前记录的项目，沿用已有管理接口权限。
读取不写回记忆、不强化、不唤醒、不产生用户反馈，也不新增睡眠审计。
工具读取计入既有取证次数和 Token 估算；没有新增持久表或备份格式。

## 验证与后续

定向测试覆盖年龄分档、偏好保护、完整条件与 Unicode 区间、长句省略、版本冲突、项目隔离及只读状态。
客户端契约测试使用真实 Remote，验证简略、展开、原文拼回和过期版本错误。
真实宿主存储验证覆盖重载后的版本绑定与只读对照。
全量验证为 255 项测试、73 项 smoke 和 25 条确定性检索场景通过；没有进行浏览器视觉验收或新增真实模型请求。
按 `dtcloud-develop-spec` 与接口设计规范完成审查；`index.js` 的 `RISK-PII-001` 为 Token 预算说明与导出描述邻近触发，人工核对后保留为误报。
